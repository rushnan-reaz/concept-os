Task A + B1/B2 (SIZE-MATCHED bthermo-performance re-measurement) — BT@9600, n=5
============================================================================
REDO 2026-07-31: see VCP_9600/summary.txt for the full context on why this
was redone (original lost with a non-worktree checkout directory that
vanished before being committed). Captured directly in the main
`concept-os` checkout, committed immediately after capture.

Transport: Bluetooth Classic rfcomm (SPP), 9600 baud, via uart3-channel /
app/bthermo/App.toml (Bluetooth config, distinct from App.vcp.toml used
for the VCP_9600/VCP_115200 batches).

Each run includes a full chip mass-erase (`stm32l4x mass_erase 0` via
OpenOCD) before the base-image reflash, same methodology as VCP_9600/
VCP_115200. The base App.ihex was rebuilt fresh for this batch (app-level
`make build` in app/bthermo) after confirming the bthermo Component.toml
was reset to version=1, then reflashed via a one-shot OpenOCD
mass_erase+program+verify+reset invocation before each run.

Wiring: D2=PB2(RECV), D3=PB1(INSTALL), D4=PB14(MIGRATE), D5=PB15(RELOC),
D6=PB0(B1), D7=PB7(B2).
