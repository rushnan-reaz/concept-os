Task A + B1/B2 (SIZE-MATCHED bthermo-performance re-measurement) — VCP@9600, n=5
============================================================================
REDO 2026-07-31: original run of this measurement was lost when the
separate git-worktree directory it was captured in disappeared before
being committed anywhere (analysis/output/ is gitignored, and that
directory was never a real git worktree of this repo -- confirmed via
`git worktree list`). This redo is captured directly in the main
`concept-os` checkout (already on branch `bthermo-performance`, commit
aca9e62 "Shrink bthermo to match delta-performance component size" --
the actual source fix survived, only the measurement data was lost) and
committed immediately after capture to prevent recurrence.

bthermo on this branch was ported to match delta-performance's own
bthermo source exactly in size (removed 8 sys_log! diagnostic calls + an
I2C bus-scan loop, swapped TMP117 for TMP102). Block size confirmed
8192 B (was 16384 B before the port), matching delta-performance exactly.

Each run includes a full chip mass-erase (`stm32l4x mass_erase 0` via
OpenOCD) before the base-image reflash, to eliminate a leftover-flash-
state artifact (page-erase counts vary run-to-run otherwise, since a
base-image reflash via ST-Link only erases the address range the base
ihex covers, not the separate flash region where OTA-pushed blocks land).

Wiring: D2=PB2(RECV), D3=PB1(INSTALL), D4=PB14(MIGRATE), D5=PB15(RELOC),
D6=PB0(B1), D7=PB7(B2). Verified via a sanity-check push before the full
5-run batch (numbers matched the pre-loss measurement closely).
